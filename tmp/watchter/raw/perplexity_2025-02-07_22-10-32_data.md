The error occurs because of a typo in the `filedialog.asksaveasfilename` call in your `get_output_file_thread` function. Specifically, the option `initial_output_dir` is not valid for `asksaveasfilename`. The correct option is `initialdir`.

Problem
-------

The error message:

```text

```

indicates that `-initial_output_dir` is not recognized by the `asksaveasfilename` method. The valid option for specifying the initial directory is `-initialdir`.

Explanation of Changes
----------------------

2.  **`default_output_filename` → `initialfile`:** To specify a default filename in the save dialog, use the `initialfile` option.
