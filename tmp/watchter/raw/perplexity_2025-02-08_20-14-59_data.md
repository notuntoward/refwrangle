**Key Parameters for Perplexity Models**
----------------------------------------

Perplexity models support several parameters that influence their behavior. When using the API, you can specify these parameters, or they will default to standard values. Here's a breakdown of the key parameters:

*   **Model**: The specific model being used, such as `"sonar"`, `"sonar-pro"`, or `"sonar-reasoning"`. If not specified, `"sonar"` is often the default [4](https://broadhurst.digital/blog/perplexity-api-add-on-for-google-sheets-user-guide) [5](https://spiceai.org/docs/components/models/perplexity) [15](https://docs.perplexity.ai/api-reference/chat-completions).
    
*   **Max Tokens**: The maximum length of the response. Default values depend on the model but can be set explicitly [4](https://broadhurst.digital/blog/perplexity-api-add-on-for-google-sheets-user-guide) [15](https://docs.perplexity.ai/api-reference/chat-completions).
    
*   **Temperature**: Controls randomness in responses. Lower values (e.g., 0.2) make outputs more deterministic, while higher values allow for more creativity [4](https://broadhurst.digital/blog/perplexity-api-add-on-for-google-sheets-user-guide) [15](https://docs.perplexity.ai/api-reference/chat-completions).
    
*   **Top-P**: Nucleus sampling parameter that determines response focus. A value closer to 1 allows for broader exploration [4](https://broadhurst.digital/blog/perplexity-api-add-on-for-google-sheets-user-guide) [15](https://docs.perplexity.ai/api-reference/chat-completions).
    
*   **Frequency Penalty**: Discourages repetition of words (≥ 0) [4](https://broadhurst.digital/blog/perplexity-api-add-on-for-google-sheets-user-guide) [15](https://docs.perplexity.ai/api-reference/chat-completions).
    
*   **Presence Penalty**: Encourages discussion of new topics (-2.0 to 2.0) [4](https://broadhurst.digital/blog/perplexity-api-add-on-for-google-sheets-user-guide) [15](https://docs.perplexity.ai/api-reference/chat-completions).
    
*   **Search Domain Filter**: Filters results based on specified domains (optional) [15](https://docs.perplexity.ai/api-reference/chat-completions).
    
*   **Search Recency Filter**: Restricts responses to recent information (e.g., "month") [15](https://docs.perplexity.ai/api-reference/chat-completions).
    

**Steps to Identify and Replicate Parameters**
----------------------------------------------

1.  **Inspect the Prompt Settings on Perplexity Website**:
    
    *   The Perplexity website dynamically selects or uses default parameters unless explicitly configured by a user.
    *   If you cannot view these details directly on the interface, assume defaults like `"sonar"` for the model and standard values for other parameters.
    
2.  **Use API Documentation for Reference**:
    
    *   Refer to the Perplexity API documentation to see how these parameters are structured in API requests. For example:
        ```json
        {
          "model": "sonar",
          "messages": [
            {"role": "system", "content": "Be precise and concise."},
            {"role": "user", "content": "How many stars are there in our galaxy?"}
          ],
          "max_tokens": 100,
          "temperature": 0.2,
          "top_p": 0.9,
          "frequency_penalty": 0,
          "presence_penalty": 0
        }
        ```
        This structure can be modified based on your needs [15](https://docs.perplexity.ai/api-reference/chat-completions).
        
    
3.  **Replicate Default Behavior**:
    
    *   If no specific parameters were set during your interaction with the model, replicate the defaults provided by Perplexity's API documentation (e.g., `"sonar"` model, temperature of 0.2, etc.) [4](https://broadhurst.digital/blog/perplexity-api-add-on-for-google-sheets-user-guide) [15](https://docs.perplexity.ai/api-reference/chat-completions).
        
    
4.  **Test and Adjust**:
    
    *   You can test your API calls with these parameters and adjust them as needed to match observed behavior from the website.
    

By following these steps and leveraging Perplexity's API documentation, you can replicate any prompt behavior from their website in your own API calls effectively.
