## User
Does github copilot work on bitbucket?

## AI answer
GitHub Copilot can function with Bitbucket repositories in certain contexts, but there are important limitations and considerations:

**Core Functionality**

*   Copilot's code suggestions work locally in supported IDEs (like VS Code) regardless of version control system [1](https://stackoverflow.com/questions/77369588/copilot-with-bitbucket) [5](https://github.com/orgs/community/discussions/72275) [13](https://stackoverflow.com/questions/78279246/how-to-use-copilot-in-vs2022-with-bitbucket-as-source-repo). You can use it with Bitbucket repositories cloned to your machine, as the tool operates on open files rather than requiring direct VCS integration [5](https://github.com/orgs/community/discussions/72275) [14](https://community.atlassian.com/t5/Bitbucket-articles/How-to-use-Codeium-s-AI-coding-assistant-with-Bitbucket/ba-p/2552360).
    

**Integration Limitations**

*   Native Bitbucket integration (e.g., repo-aware context) isn't officially supported - Copilot's advanced features are optimized for GitHub repositories [1](https://stackoverflow.com/questions/77369588/copilot-with-bitbucket) [5](https://github.com/orgs/community/discussions/72275) [13](https://stackoverflow.com/questions/78279246/how-to-use-copilot-in-vs2022-with-bitbucket-as-source-repo).
    
*   Some users report authentication prompts for GitHub credentials when using Copilot with non-GitHub repos in certain IDEs [13](https://stackoverflow.com/questions/78279246/how-to-use-copilot-in-vs2022-with-bitbucket-as-source-repo).
    

**Configuration Steps**

1.  Install Copilot in your preferred IDE (VS Code, JetBrains, etc.) [4](https://www.atlassian.com/blog/bitbucket/github-copilot-bitbucket-jira-and-confluence)
2.  Clone Bitbucket repositories locally
3.  Open files in your editor to access basic code completion features [4](https://www.atlassian.com/blog/bitbucket/github-copilot-bitbucket-jira-and-confluence) [14](https://community.atlassian.com/t5/Bitbucket-articles/How-to-use-Codeium-s-AI-coding-assistant-with-Bitbucket/ba-p/2552360)

**Security Considerations**

*   Private code protection depends on your Copilot license terms - some enterprise agreements prohibit using private code for training [1](https://stackoverflow.com/questions/77369588/copilot-with-bitbucket) [14](https://community.atlassian.com/t5/Bitbucket-articles/How-to-use-Codeium-s-AI-coding-assistant-with-Bitbucket/ba-p/2552360)
*   GitHub's data handling policies apply regardless of VCS - review their terms for compliance [1](https://stackoverflow.com/questions/77369588/copilot-with-bitbucket) [5](https://github.com/orgs/community/discussions/72275)

**Alternatives & Extensions**

*   Atlassian's Rovo extension enhances Copilot with Jira/Confluence context in VS Code [4](https://www.atlassian.com/blog/bitbucket/github-copilot-bitbucket-jira-and-confluence)
*   Codeium offers Bitbucket-integrated AI coding assistance as an alternative [14](https://community.atlassian.com/t5/Bitbucket-articles/How-to-use-Codeium-s-AI-coding-assistant-with-Bitbucket/ba-p/2552360)

While Copilot works for basic code completion with Bitbucket-hosted projects, teams wanting deep VCS integration should consider GitHub repositories or complementary tools like Atlassian's AI extensions.
